# 바탕화면 달력

바탕화면에 붙는 월간 달력. 칸을 더블클릭하면 노션 「긴영상 후보」 표의 후보가 뜨고, 고르면 그 행의 촬영일에 날짜가 적힌다(노션이 원본이라 같은 표를 쓰는 사람끼리 촬영일이 같이 보인다). 칸 메모·색은 PC마다 따로.

## 설치
1. [Releases](../../releases/latest)에서 `desk_cal.exe`를 받아 더블클릭
   - 「Windows의 PC 보호」가 뜨면 **추가 정보 → 실행** (서명 없는 exe라 처음 한 번)
2. 알아서 `%LOCALAPPDATA%\nabu-desk-cal\`로 옮겨지고 윈도우 켤 때 자동으로 뜬다. 받은 파일은 지워도 된다
3. 달력 오른쪽 위 ⚙ → **노션 토큰**·**후보 표 링크** 넣고 [연결]. 위치·크기도 여기서

## 업데이트
자동. 켤 때와 24시간마다 새 릴리스를 확인해 받아 두고, 후보 창·설정 창이 닫혀 있을 때 바꿔 띄운다. 지금 버전은 ⚙ 아래쪽.

## 끄기
달력 오른쪽 클릭 → 달력 끝내기. 자동 실행은 작업 관리자 → 시작 앱에서 끈다.
